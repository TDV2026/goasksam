# Phase 2 — Card routing plan (Hagerty / PCARMarket as Card 1/2)

Status: **PLAN FOR REVIEW. Do not build until approved.**

Goal: let Hagerty and PCARMarket surface as Card 1 / Card 2 for the segments
where the 180-day data proves they win, without violating rule 1 (never
recommend a platform the specific car's own comps don't support) or rule 14
(platforms judged model-specific).

Decisions already locked (from review):
- **Hybrid routing**: a curated win-condition table decides *eligibility*; the
  car's own live comps must *back* the pick, else fall back to live-evidence.
- **PowerSeller flow unchanged** (no yes/no comparison gate — that stays locked).
- **No timelines** ("22 days vs 45 days" is not in the data — rule 1).
- **Real evidence window** on the plate, never a hardcoded "PAST 180 DAYS".

---

## 1. Data flow

Today (unchanged foundation):
1. `sellerDecision.js` fetches per-search comps from OCD across ALL sources
   (BaT, C&B, Hagerty, PCARMarket, consignment) → `evidenceByPlatform`.
2. `buildRouteFit` scores each `ROUTE_POLICIES` platform from its own evidence
   (`evidenceSales`, median, `pricePremium`, sell-through, etc.).
3. `decide()` picks `bestRoute` (routable, top score) → `decision.routeFit.routes`.
4. Frontend (`js/result.js`) renders `routeOptions[0]` = Card 1, `[1]` = Card 2.

Phase 2 inserts ONE new step between (2) and (3):

```
buildRouteFit -> [NEW] applyWinConditions(routes, vehicle) -> decide()
```

`applyWinConditions`:
- Resolves the vehicle's `{make, model, generation}` (already available; the
  generation comes from `lib/generations.js`).
- Looks up the curated table for a candidate platform + confidence.
- Checks the candidate's LIVE evidence in `evidenceByPlatform` (the backing gate).
- If eligible AND backed → boosts that platform's route so it can be Card 1/2;
  attaches a `winCondition` fact (platform, confidence, segment label) to the
  route for the copy layer.
- If not backed → no change (normal live-evidence routing stands).

Nothing about the fetch, the ladder, or the evidence math changes. This is a
re-ranking layer, fully driven by real per-car evidence + a curated eligibility
gate.

---

## 2. Where the curated table lives

**Recommendation: a version-controlled JS constant**, `lib/winConditions.js`,
in the same spirit as `ROUTE_POLICIES` and `CURATED_GENERATIONS`. NOT a Supabase
table, NOT a live `sales_archive` query per request.

Rationale:
- The 180-day share is a *periodic snapshot*, not real-time — a constant is the
  honest representation and keeps routing deterministic/auditable.
- No new per-request DB dependency (sellerDecision already has enough I/O).
- Regenerated by re-running the committed analysis (`denominators.js`) and
  pasting the output; the file documents its own provenance + date + sample size.

Shape:
```js
// Regenerated from scripts/denominators.js on <date>. share = 180-day.
export const WIN_CONDITIONS = [
  // { make, model, generation?, yearMax?, platform, share, n, confidence }
  { make: "Chevrolet", model: "Camaro", platform: "hagerty", share: 12.4, n: 234, confidence: "high" },
  { make: "Ford", model: "Thunderbird", platform: "hagerty", share: 10.3, n: 126, confidence: "high" },
  { make: "Jaguar", model: "XJ", platform: "hagerty", share: 13.6, n: 81, confidence: "moderate" },
  { make: "Chevrolet", model: "Chevelle", platform: "hagerty", share: 11.5, n: 78, confidence: "moderate" },
  { make: "Porsche", model: "911", platform: "pcarmarket", share: 10.2, n: 364, confidence: "high" }, // air-cooled bucket
  { make: "Porsche", model: "944", platform: "pcarmarket", share: 14.5, n: 62, confidence: "moderate" },
  { make: "Porsche", model: "964", platform: "pcarmarket", share: 11.7, n: 60, confidence: "moderate" },
  // low-confidence (n<50) entries kept but flagged, never Card 1: Impala, 3100, 718
];
```

Key detail — the air-cooled 911 split is FREE: OCD/our resolver file modern 911s
as their own models (996/997/991/992). So `model: "911"` in the table matches the
air-cooled/classic bucket only; water-cooled generations never match this row.
`964` is listed explicitly. No year math needed for the common case; add
`yearMax`/`generation` only where a model spans eras (documented per row).

## 3. Eligibility gate + live-comp backing

```
applyWinConditions(routes, vehicle, evidenceByPlatform):
  wc = WIN_CONDITIONS.find(match make + (model or generation) of vehicle)
  if !wc: return routes unchanged            # no curated win condition

  candidate = routes.find(r => r.policyKey === wc.platform)
  live = evidenceByPlatform[wc.platform]

  BACKED = live && live.evidenceSales >= BACKING_MIN     # e.g. >= 3 real comps for THIS car
  if !BACKED: return routes unchanged          # rule 1: no elevation without the car's own proof

  if wc.confidence === "high":
     mark candidate eligible for CARD 1        # BaT becomes Card 2
  else (moderate):
     mark candidate eligible for CARD 2 only   # BaT stays Card 1
  # low confidence (n<50) never elevates automatically; log only

  attach candidate.winCondition = { platform, confidence, segmentLabel }
  return re-ranked routes
```

Guardrails:
- `BACKING_MIN` (open decision, propose **3**): the platform must have at least
  N real comparable sales for THIS car in the fetch window. Below that, the
  global table does not get to speak — the live-evidence pick stands.
- The measured share (12.4% etc.) is a **routing signal only**, never rendered
  to users (same treatment as momentum telemetry). Cards speak qualitatively
  ("specialist audience for air-cooled 911s").
- If two win conditions could apply (rare), highest confidence then highest `n`.
- No win condition, or not backed → existing ladder/regional-floor behavior,
  untouched.

Decision tree it produces (matches the reviewed intent):
```
air-cooled 911 / 964 + PCARMarket has >=3 comps   -> Card 1 PCARMarket, Card 2 BaT
Camaro/Thunderbird + Hagerty has >=3 comps        -> Card 1 Hagerty,   Card 2 BaT
moderate wins (XJ, Chevelle, 944, 964) + backed   -> Card 1 BaT,       Card 2 niche platform
996/997/991/992 (no win condition)                -> Card 1 BaT,       Card 2 C&B (live share)
everything else                                   -> unchanged (live evidence / floor)
```

   fabricated.

   depth), never hardcode 180.
5. **Display names** — verify `platformDisplayName` maps `hagerty` ->
   "Hagerty Marketplace" and `pcarmarket` -> "PCarMarket".
6. **Raw numbers** — already stripped in Phase 1; keep the smoke guards.
